📚 How AES-256 Works
🔑
Step 1

Key Expansion

Password → PBKDF2 + SHA-256 → 256-bit key (32 bytes).

🎲
Step 2

IV Generation

A random 128-bit IV is generated — every encryption is unique.

🧱
Step 3

Block Splitting

Message split into 128-bit blocks; each chained with the previous (CBC).

🔄
Step 4

14 Rounds

SubBytes → ShiftRows → MixColumns → AddRoundKey, repeated 14×.

📦
Step 5

Output

IV + ciphertext packed together and encoded as Base64.

🔓
Decrypt

Reversal

Same key + IV runs all 14 rounds in reverse to recover the original message.
